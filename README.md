# 🩸 Blood Bank Management System

The Blood Bank Management System is a full-stack, web-based application developed to streamline the process of blood donation, request, and inventory management. It connects **donors**, **patients**, and **hospitals** on a single platform, while allowing **admins** to manage data securely and efficiently.

Developed using **ReactJS**, **Tailwind CSS**, **Python (Flask)**, and **PostgreSQL**, the platform features a responsive, user-friendly UI with dynamic form handling and real-time notifications via **SMS and email**.

---

## 🔍 Project Overview

The system supports:

- 🩸 **Donors**: Register and log blood donation details (age, blood group, date, quantity, contact, etc.)
- 🧑‍⚕️ **Patients**: Request specific blood types for emergencies
- 🏥 **Hospitals**: Register to partner and manage requests
- 🔐 **Admins**: Authenticate and manage data
- 📦 **Inventory Viewer**: Real-time display of available blood groups and quantities
- 📧 **Notifications**: SMS/email alerts for requests and confirmations



🎯 Features

 👤 User Interface

- **Home Page**: GIF banner, motivational slogan, About Us and Contact sections
- **Donor Page**: Registration form with disease info and donation history
- **Patient Page**: Request form with date, blood group, and personal details
- **Hospital Page**: Form for registering hospitals with location and contact
- **Inventory Page**: Table showing current stock by blood type
- **Login Page**: Authentication for secure backend access

 🔐 Admin Functions

- Admin authentication via login
- Backend routes to validate and process form submissions
- PostgreSQL-based CRUD operations
